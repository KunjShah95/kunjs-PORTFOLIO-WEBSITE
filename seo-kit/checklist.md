# Client SEO ship gate

Do not call the work done until every box is checked.

## On-site

- [ ] One `<h1>` per page, sequential headings, real `<a href>` links.
- [ ] Unique title (≤60 chars) and description (≤158) per page, with canonical.
- [ ] Proof page leads with a direct answer an assistant can quote verbatim.
- [ ] Every number has a "where to check" link and a "what it excludes" note.
- [ ] One case study per shipped project, each with method, limitations and source.
- [ ] Two commercial pages: transactional hire page and local/consulting page.
- [ ] Freelancer-vs-agency comparison table with honest criteria.
- [ ] FAQ with `FAQPage` JSON-LD; `<summary>` contains plain text, not a heading.
- [ ] New pages added to sitemap, Markdown twins, footer/index internal links.
- [ ] `robots.txt` allows GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended.
- [ ] `llms.txt`, `llms-full.txt`, `pricing.md`, `services.md` exist and are current.

## Off-site

- [ ] GitHub profile Website field points at the canonical domain.
- [ ] Profile README has the proof and hire links with descriptive anchors.
- [ ] READMEs of owned repos cited on the site carry the backlink footer.
- [ ] One linkable case-study post published on the site itself.
- [ ] Post shared on LinkedIn and one dev community with the same canonical URL.
- [ ] No links placed in repos the client does not own or in unrelated directories.

## Measurement

- [ ] SerpApi baseline recorded for 2–3 commercial queries.
- [ ] Exa/GSC index check scheduled biweekly for new pages.
- [ ] Domain rating baseline recorded; reviewed monthly, not weekly.
- [ ] Raw HTML of each new page contains the main keyword (SSR check).
